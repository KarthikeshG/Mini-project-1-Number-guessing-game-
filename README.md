# Number Guessing Game - Mini Project 1

A web-based version of the classic Number Guessing Game. The system generates a random number between 1 and 100, and the player must guess it using the fewest attempts possible. 

## Features
* **Random Target:** Generates a new random number from 1 to 100 on every page load.
* **Input Validation:** Prevents crashes by checking if the user entered a valid number or text.
* **Dynamic Feedback:** Guides the user by telling them if their guess is too high or too low.
* **Quit Option:** Type "Q" or "q" at any time to exit the game.
* **Browser Ready:** Built with HTML, CSS, and JavaScript. No installations required.

## How to Run
1. Save the `index.html` file to your computer.
2. Double-click the file to open it in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Type your guess into the input box and click "Submit" to play!
